KAYAK STRATEGIC ADVISORS — WORD LETTERHEAD (A4)

1. Install the fonts first: open the Fonts folder, select all .ttf files and choose Install
   (Windows) or double-click each and Install Font (Mac). Restart Word.
2. KSA_Letterhead_A4.dotx  — the template. Double-click it to start a new letter each time,
   or save it to your Office Custom Templates folder so it appears under File > New.
   KSA_Letterhead_A4.docx  — the same letterhead as an ordinary document.
3. Replace every [bracketed] placeholder. The logo, address block, footer line and the
   teal/saffron bar sit in the header and footer, so they repeat on every page.
4. Body text: Source Serif 4, 10.5 pt. Headings and signature: Archivo.
   If the fonts are not installed, Word substitutes; use Georgia and Arial instead.
